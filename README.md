# Nasa-Viewer
NASA Viewer es una web ASP.NET Core Razor Pages que integra APIs oficiales de NASA (APOD, EPIC, Image Search y GIBS). Permite explorar imágenes espaciales, galerías Bootstrap, mapas satelitales interactivos y búsquedas dinámicas. Tecnologías: C#, Razor Pages, Bootstrap, Leaflet.js, HttpClient y APIs REST de NASA.

# 🌌 NASA Viewer

NASA Viewer es una aplicación web desarrollada con ASP.NET Core Razor Pages que consume múltiples APIs oficiales de NASA para explorar imágenes espaciales, galerías satelitales y mapas interactivos.

Tecnologías: C#, Razor Pages, Bootstrap, Leaflet.js, HttpClient y APIs REST de NASA.

---

# 🚀 Funcionalidades actuales

- 🌠 APOD (Astronomy Picture of the Day)
- 🌍 EPIC Earth Images Carousel
- 🔭 NASA Image Search
- 🛰️ Integración experimental con GIBS
- 🎠 Carruseles Bootstrap
- 🌎 Mapas interactivos con Leaflet.js
- 🔎 Búsquedas dinámicas de imágenes NASA

# 🔑 Obtener API Key de NASA

1. Ingresar al portal oficial:
https://api.nasa.gov/

2. Generar una API Key gratuita.

3. Explorar los endpoints disponibles y sus parámetros:
- APOD
- EPIC
- Image Search
- Mars Rover Photos
- GIBS
- NeoWs
- Earth
- entre otros.
